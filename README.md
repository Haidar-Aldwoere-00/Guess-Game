# JavaScript Logic Game 🎮

An interactive web-based game built to practice advanced JavaScript logic, DOM manipulation, and CSS animations.

## 📌 Project Overview
This project is a functional game designed to demonstrate the power of Vanilla JavaScript. It focuses on handling user events, managing game states, and creating a smooth interactive experience.
